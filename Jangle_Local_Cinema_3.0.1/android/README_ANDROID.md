# Jangle Android — сборка APK

Это нативная Android-оболочка для существующего веб-приложения Jangle. Она добавляет только недостающий системный доступ к папке библиотеки через Storage Access Framework (SAF); основной интерфейс и логика кинотеатра остаются веб-приложением.

## Требования

- Android Studio с поддержкой Android Gradle Plugin 8.7.3.
- JDK 17 (Android Studio может использовать встроенный JBR).
- Интернет при первой Gradle Sync для загрузки Android Gradle Plugin и AndroidX-зависимостей.
- Устройство Android 7.0+ (API 24+).

## Сборка

1. Откройте в Android Studio именно папку `android/`, а не корень ZIP.
2. Подтвердите Gradle Sync и дождитесь загрузки зависимостей.
3. Выполните **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
4. Debug APK: `app/build/outputs/apk/debug/app-debug.apk`.
5. Для постоянной установки/распространения используйте **Build → Generate Signed Bundle / APK** и создайте собственный ключ подписи.

## Выбор библиотеки

При нажатии «Выбрать папку библиотеки» Android показывает собственный системный каталог. Выберите папку, внутри которой расположены `content/` и `settings/`. Разрешение сохраняется, поэтому повторно выбирать библиотеку после каждого запуска не нужно. Чтобы вручную переключить папку, используйте пункт «Сменить директорию» в настройках приложения.

На Android 11+ ограничения SAF не позволяют выбирать некоторые системные папки, в том числе корень внутреннего общего хранилища, `Download/`, `Android/data/` и `Android/obb/`. Создайте отдельную папку библиотеки, например `Documents/JangleLibrary/` или `Movies/JangleLibrary/`.

## Что реализует Android-мост

- системный выбор дерева каталогов `ACTION_OPEN_DOCUMENT_TREE`;
- сохранение URI-разрешения `takePersistableUriPermission`;
- чтение и перечисление вложенных папок;
- чтение/перезапись файлов метаданных;
- сохранение изображений редактора;
- потоковое чтение видео без передачи видеофайла в JavaScript Base64;
- byte-range для нормальной перемотки видео;
- создание каталогов и попытка физического переименования.

Веб-страница загружается локально через `WebViewAssetLoader`. У приложения нет разрешения на общий доступ ко всему хранилищу; доступен только каталог, который пользователь сам выбрал через SAF.

## Проверка

После установки откройте приложение, выберите корень `sample-library` (если скопировали его в доступное место) или свою библиотеку. Каталог должен заполниться. Проверьте открытие серии, перемотку и сохранение настройки. В разделе «Система» режим доступа должен отображаться как «Чтение и запись».


#### Если GitHub Actions пишет `Failed to find package 'tools'`

Убедитесь, что workflow использует `android-actions/setup-android@v4.0.2` и параметр `packages: 'platform-tools'`. Не используйте `android-actions/setup-android@v3`: старая версия может запрашивать снятый с публикации пакет SDK `tools`. Готовый workflow находится в `.github/workflows/build.yml` в корне архива.
