# Jangle — Local Cinema 3.0.1

Локальный кинотеатр для собственной библиотеки фильмов, сериалов и видео. Проект написан на обычных HTML, CSS и JavaScript. Нет Python, Node-сервера, внешних библиотек, CDN и обязательного подключения к интернету.

## Запуск в браузере

1. Распакуйте архив в любую папку.
2. Откройте `index.html` в актуальном Chrome или Microsoft Edge.
3. Нажмите **«Выбрать папку библиотеки»** и укажите корневую папку своей видеотеки.
4. Разрешите чтение и запись, если хотите использовать редактор и сохранять настройки прямо в `.md`-файлы.

В корне библиотеки должны находиться папки `settings` и `content`. При первом выборе приложение создаст их, если они отсутствуют.

Для установки как PWA (иконка и отдельное окно приложения) разместите эти статические файлы на HTTPS-хостинге и установите страницу через меню браузера. Service Worker кэширует только оболочку приложения, но не ваши видео. В актуальном Chrome на Android выбор папки доступен через File System Access API при запуске с безопасного HTTPS-источника.

### Режим совместимости

Если браузер не поддерживает File System Access API, кнопка **«Открыть папку в режиме импорта»** использует стандартный для Chromium-подобных браузеров выбор каталога (`webkitdirectory`). В этом режиме можно просматривать доступные файлы в течение текущей сессии, но нельзя записывать изменения в исходную папку. После перезагрузки каталог потребуется выбрать снова.

Для полноценной работы редактора и записи рекомендуется Chrome или Edge на компьютере. Разрешение на папку может потребоваться выдать повторно после перезапуска браузера.

## Структура библиотеки

```text
Выбранная папка/
├── settings/
│   └── user_settings.md
└── content/
    └── Название категории/
        ├── category_info.md
        └── Название произведения/
            ├── poster.png
            ├── header.png
            ├── product_info.md
            ├── Сезон 1/
            │   ├── season_info.md
            │   ├── серия_1.mp4
            │   └── серия_2.mp4
            └── Сезон 2/
                ├── season_info.md
                └── серия_1.mp4
```

Файлы `poster.png` и `header.png` необязательны. Если постера нет, приложение покажет аккуратную текстовую заглушку. При замене картинки в редакторе можно выбрать любой формат изображения — приложение преобразует его в PNG.

### Поля метаданных

`category_info.md`:

```text
'password' = empty
'order' = 1
'description' = "Описание категории"
'age_restriction' = empty
```

`password` — пустое значение отключает защиту. Любой непустой пароль включает экран ввода пароля. Пароль хранится в обычном текстовом файле: это защита интерфейса от случайного просмотра, а не криптографическое шифрование файлов.

`age_restriction` принимает `empty` или `yes`; можно также указать число, например `21`, чтобы изменить маркировку. Категория скрывает содержимое за предупреждением, но пользователь может нажать «Показать». Детский режим скрывает такую категорию.

`product_info.md`:

```text
'name' = "Полное название произведения"
'description' = "Описание произведения"
'product_age_restriction' = empty
'publisher' = "Студия / автор / канал"
```

`product_age_restriction` работает как предупреждение перед открытием произведения. Для маркировки можно указать `yes`, `18` или `21`. В детском режиме произведение скрывается.

`season_info.md`:

```text
'order' = 1
'description' = "Описание сезона"
```

Для упорядочивания категорий, произведений и сезонов используется числовое поле `order`. Элементы с заданным порядком отображаются первыми; элементы без порядка располагаются по алфавиту. Для произведений приложение также читает `order` из `product_info.md`.

### Настройки и история

Настройки сохраняются в `settings/user_settings.md`:

```text
'history' = yes
'search' = yes
'child_mode' = no
'editor_mode' = no
'history_json' = "{}"
```

`history_json` содержит позиции просмотра и служебные сведения по сериям. Приложение дополнительно держит локальную копию в хранилище браузера, чтобы не терять последние секунды просмотра при закрытии вкладки.

## Демонстрационная библиотека

В каталоге `sample-library/` находится готовый пример структуры с демонстрационным постером, header-картинкой и коротким MP4-видео. Выберите `sample-library` в качестве библиотеки, чтобы сразу проверить каталог и плеер. Папку можно копировать и использовать как основу для своей коллекции.

## Что реализовано

- Выбор локальной папки, повторное подключение сохранённой папки через разрешение браузера.
- Сканирование категорий, произведений, сезонов и видеофайлов.
- Категории с паролем, возрастное предупреждение для категории и произведения, детский режим.
- Горизонтальные ленты произведений, постеры, шапка произведения, вкладки сезонов, список серий.
- Генерация превью серии из видеокадра средствами HTMLVideoElement и Canvas, без стороннего декодера.
- История просмотра и сохранение позиции, быстрый переход к продолжению.
- Поиск по категориям, произведениям и именам файлов серий.
- Редактор названий и описаний, студии, порядка, постеров и header-картинок.
- Перетаскивание категорий и произведений для изменения порядка.
- Встроенный плеер: воспроизведение/пауза, клавиша Space, переходы на ±20 секунд, предыдущая/следующая серия, шкала времени, поворот, полноэкранный режим, режимы отображения и подсветка краёв.

## Важные ограничения браузерной платформы

**1. Поддержка видео определяется браузером и кодеком.** Приложение может открыть видеофайл только в том случае, если встроенный медиадвижок браузера умеет декодировать его контейнер и аудио/видеокодеки. MP4 с H.264/AAC и WebM обычно имеют наилучшую совместимость. Наличие файла `.mkv`, `.avi` или другого расширения не гарантирует воспроизведение. Приложение не конвертирует видео.

**2. Превью извлекаются из декодируемого видео.** Кадр берётся приблизительно на 12% длительности (не дальше 15 секунд). Если браузер не смог прочитать видео или его кадр, останется заглушка. Без FFmpeg/WebCodecs-плагина или отдельного декодера нельзя гарантировать извлечение кадров из всех форматов.

**3. «Оригинал» означает исходный размер кадра в CSS-пикселях.** Видео не увеличивается и не обрезается. Если исходный кадр больше области экрана, область плеера прокручивается. Поворот применяется поверх выбранного режима отображения.

**4. Подсветка использует кадр текущего видео.** Плеер периодически обновляет небольшую копию текущего кадра и размывает её позади видео. Поэтому фон соответствует содержимому, но обновляется с небольшим интервалом, а не каждый кадр.

**5. Режим редактора использует возможности File System Access API.** В браузерах без API редактирование отключено. Если браузер не поддерживает переименование каталога через File System API, новое отображаемое имя сохраняется в `name` внутри `.md`, а физическое имя папки остаётся прежним. Порядок в любом случае записывается в метаданные.

**6. Название устройства.** Обычная веб-страница не получает системное имя компьютера/телефона из соображений приватности. На странице «Система» выводится доступная браузеру платформа устройства.

## Android APK с выбором папки

В архив добавлен отдельный Android Studio-проект в каталоге `android/`. Он содержит WebView-оболочку и нативный мост на Android Storage Access Framework (SAF). В APK кнопка «Выбрать папку библиотеки» открывает системный выбор каталога Android; выбранная папка и разрешение сохраняются после перезапуска приложения. Мост поддерживает сканирование подпапок, чтение метаданных, потоковое чтение видео с поддержкой byte-range, запись настроек и изображений, создание папок и переименование. Сама веб-логика кинотеатра при этом не переписана.

Чтобы собрать APK:

1. Откройте папку `android/` в Android Studio.
2. Дождитесь завершения Gradle Sync.
3. Выберите **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
4. Тестовый APK появится в `android/app/build/outputs/apk/debug/app-debug.apk`. Для публикации соберите подписанную Release-версию через **Generate Signed Bundle / APK**.

После установки откройте приложение, нажмите «Выбрать папку библиотеки» и выберите папку, внутри которой лежат `content/` и `settings/`. На Android 11 и новее системные ограничения не позволяют выбрать корень внутреннего общего хранилища, `Download/`, `Android/data/` и `Android/obb/`; создайте отдельную папку библиотеки, например `Documents/JangleLibrary/` или `Movies/JangleLibrary/`.

**Важно о сторонних Web-to-APK-конвертерах:** обычная HTML-страница не может самостоятельно вызвать `ACTION_OPEN_DOCUMENT_TREE`. Для полноценного доступа к папкам APK-оболочка должна реализовать нативный SAF-мост. Поэтому для работы именно в APK используйте добавленный проект `android/`, либо подключите такой же мост в конструкторе, если он позволяет добавлять собственный Android JavaScript Interface. Простое повторное упаковывание сайта в стандартный WebView без нативного моста проблему не исправит.

Подробности реализации и контракта находятся в `ANDROID_WEBVIEW.md`; описание сборки Android-проекта — в `android/README_ANDROID.md`.
