# Jangle 3.0.1 — исправленная сборка APK через GitHub Actions

Этот архив подготовлен под сборку через GitHub Actions. Он содержит веб-приложение, Android WebView-оболочку с SAF и готовый workflow.

## Почему предыдущий APK открывался, но выбор папки не работал

В предыдущем workflow Android-часть и JavaScript использовали **разные интерфейсы**:

- веб-адаптер Jangle ожидал объект `window.JangleAndroidBridge`;
- Kotlin-код из вашего workflow регистрировал объект под именем `AndroidJangle`;
- веб-адаптер ожидал методы `getLibraryInfo`, `requestLibrary`, `list`, `readText`, `getMediaUrl`, `writeText`, `writeFileBase64`, `createDirectory`, `rename` и callback `JangleAndroidBridgeCallback`;
- Kotlin-код вместо этого отправлял события `jangle-android-library` / `jangle-android-error`, на которые приложение не подписано.

Поэтому приложение запускалось, но веб-часть не могла вызвать нативный выбор каталога. Кроме того, рабочий `js/android-adapter.js` должен обязательно попасть внутрь APK до `app.js`.

В этом проекте обе стороны используют один и тот же протокол: `JangleAndroidBridge` + `JangleNative`.

## Как поставить проект в GitHub

1. Распакуйте архив.
2. Скопируйте в корень вашего GitHub-репозитория папку `Jangle_Local_Cinema_3.0.1` и папку `.github` из этого архива. Согласитесь на замену старой папки приложения и старого workflow.
3. Убедитесь, что в репозитории появился файл `.github/workflows/build.yml`.
4. Удалите или отключите старый workflow, который создавал папку `android_build`: не оставляйте две конкурирующие сборки APK.
5. Сделайте commit и push в ветку `main` или `master`, либо запустите workflow вручную через вкладку **Actions**.
6. Откройте завершённый запуск Actions и скачайте artifact `Jangle_Local_Cinema_3.0.1_APK`. Внутри будет `app-debug.apk`.

## Как проверить работу APK

1. Установите APK на Android.
2. Запустите Jangle и нажмите **«Выбрать папку библиотеки»**.
3. В системном проводнике выберите корневую папку библиотеки — ту, внутри которой находятся `content` и `settings`.
4. Разрешите доступ. Каталог должен отобразить категории и произведения.
5. Для проверки чтения откройте серию. Для проверки записи включите режим редактора и измените описание или изображение: изменение должно сохраниться в выбранной папке.

Android ограничивает выбор некоторых системных каталогов через SAF. Используйте отдельную папку, например `Documents/JangleLibrary` или `Movies/JangleLibrary`. Не выбирайте `Android/data`, `Android/obb` или корень внутреннего хранилища.

## Что входит в нативную интеграцию

- системный выбор папки через Android Storage Access Framework;
- сохранение разрешения после перезапуска;
- обход вложенных папок и чтение `.md`;
- запись настроек, метаданных и изображений;
- выдача видео через WebView с поддержкой HTTP byte ranges для перемотки;
- тот же веб-интерфейс и основной `app.js` без замены логики кинотеатра.

Сборка создаёт Debug APK. Для публикации и распространения APK потребуется отдельная подписанная Release-сборка.


### Исправление ошибки `Failed to find package 'tools'`

В workflow используется `android-actions/setup-android@v4.0.2` с явным `packages: 'platform-tools'`. Старый пакет SDK `tools` больше не публикуется Google, а `setup-android@v3` мог пытаться установить именно его. Лицензии SDK принимает само действие; отдельный вызов `yes | sdkmanager --licenses` больше не нужен. Остальные параметры сборки и исходники приложения не изменены.
